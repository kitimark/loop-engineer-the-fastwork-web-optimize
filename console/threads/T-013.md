## #3 · lead · 2026-10-02T06:42:52.633Z

About your C-017 note (recording with Xcode), checked:
1) The page you linked records your taps into UI-test code; it doesn't make a screen video (Apple's 'Recording UI automation for testing' page).
2) Xcode can keep a screen video of a UI test run in the test results, with screen capture set to Video in the test plan. That is confirmed by an Apple forum thread and an open-source project, not by an Apple doc page. It doesn't suit us: our gesture driver is one test that runs for hours, so the video would only be written when it stops, as one huge file. Its frame rate isn't documented, and the test needs every frame at 60 Hz.
3) So we use QuickTime's USB recording. Our script could control QuickTime, but it can't open a new recording window the first time. Please do console step C-018: open QuickTime > File > New Movie Recording, pick the iPhone as camera and Maximum quality, leave the window open without pressing record. Then the script starts and stops one recording per run.
