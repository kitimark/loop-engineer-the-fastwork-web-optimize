How much of tasks that we are allow to do testing in the parallel ?

## #7 · lead · 2026-10-01T21:47:40.727Z

Up to 3 'units' at once. Each kind of test job costs units:
- a headless Chrome check, one functional Chrome test file, or a mechanism count = 1 unit;
- a full test suite (npm test) = 2 units;
- a Simulator check = 3 units (the Simulator is one shared device, so it runs alone).
So in practice: 3 small checks side by side, or 1 test suite + 1 small check, or 1 Simulator check.
Two safety rules:
- a new job doesn't join while the Mac is very busy (load above 16);
- each shared job is capped at 5 min.
Timing measurements always get Chrome alone, and the iPhone runs one test at a time.
The limit can go up to 4 units. I kept 3 for the first hours, to see that tests don't time out under load. If it runs clean, I can raise it; just say so.
