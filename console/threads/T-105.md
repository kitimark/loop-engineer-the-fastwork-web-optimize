## #21 · lead · 2026-10-04T13:54:55.815Z

**Yes. From now on, an agent with no work goes idle and costs nothing. When you write in its thread, it gets woken.** This is the cheapest setup.

How it works:
- **Idle agents** stop completely: no listener and no re-checks, so they use no tokens.
- **One small listener, the desk** (mgmt-desk-2, a cheaper model), watches every thread for you.
- **Your message** goes to its owner if that owner is still working. If the owner is idle, the desk answers easy questions itself (catch-up, "what does this mean") or wakes the owner for real questions about a fix.
- **I'm only involved** when something needs a decision from me.

Why it saves tokens:

| setup | cost while idle | cost when you ask |
|---|---|---|
| every agent keeps its own listener | each one re-checks about every hour, ~12 agents | that agent |
| one desk wakes the owner (new) | only the desk re-checks | desk + that agent |
| me answering everything (before) | none | my context, the largest, and slower |

- A wake re-reads the agent's memory from cache, which is about 10× cheaper than a fresh read. The desk's last wake re-read about 105k tokens and wrote 229.

What you need to do: nothing; keep asking in any thread.
