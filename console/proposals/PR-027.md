## Problem

A bug in the original site, which we can fix: at the end of the page the nav's 'Join waitlist' button jumps up before it fades.
- When the nav pill starts growing into the end menu, the button rises 8 px and blurs while still fully visible.
- Only after that does it fade out, so you see the jump.
- Its other exits don't move: when it hides into the pill at the top of the page it just fades.
- The original site has the same jump: it is in the site's own style rules, not caused by our fixes.
- Measured per frame in Chrome and in the iOS Simulator; see the numbers in each option.

## Idea

Three options, all on option B, the end-menu build you accepted (fix A plus the reveal).
- A: keep it as today.
- Fade only (recommended): no jump and no blur; the button fades out like it does at the top of the page.
- No jump: no jump, but the blur and fade stay as today.
- One style line changes; nothing else on the page moves.
- Try it on the Mac now; the phone Try-it pages come after the current iPhone checks.
What you need to do: try the options and pick one.

Risk: None.
