## Problem

Answer first: K draws the same digit roll as the version you accepted (V9), with 3-4x fewer animation steps. The iPhone check found no extra slow frames. We recommend landing it.

What changes
- V9 (accepted, landed): each rolling digit gets 144 animation steps per roll, and 343 for a 0-to-9 roll.
- K: the same path written as exact curve pieces: 52 steps per roll, and 66 for a 0-to-9 roll.
- Only the big countdown at the top (the hero clock). Nothing else changes.

Why you decide
- It changes the version you accepted, so it comes back to you, even though the path is the same by construction.
- In the iPhone Simulator, K's still frames are closer to the original roll than V9's are (table below).

Your research request (PR-017 note)
- Done (card T-096, counts only). In Chrome, V9 removes the countdown's script from about 270 of every 480 screen frames, and the frames left do no more work. In WebKit, each roll start adds one extra style step. Not yet tested whether K changes that step. Details are in the thread.

Codes used here
- C8: the original digit strips (the roll before PR-017). V9: the accepted PR-017 roll. K (or VK): V9 with fewer steps.
- Animation step (keyframe): one point the graphics chip moves the digit through.
- CSS px: a page pixel. The phone screen has 3 x 3 screen pixels per CSS px.

## Looks the same?

At rest and at the end of every roll: identical to V9 and to C8 (iPhone Simulator: roll ends 0 px apart, the same 14 digit images at rest). While a digit rolls: the same path as V9 (equal to 0.00000000000001 of a digit cell when worked out offline). In Chrome both stay inside the original roll's own frame-to-frame variation.

## Options

### Option land-k: Land K

Replace V9's animation steps with K's: the same path in 3-4x fewer steps. Only the hero clock changes. No swipe test is needed from you; Try it shows A = V9 and B = K.

Risk: Not fewer with K (iPhone Simulator, OBSERVED): the digit images WebKit paints when a roll starts (long rolls: 10-15 with K, 9-12 with V9, overlapping). Not tested with K: the extra style step at each roll start found in T-096. Not checked on the phone: scroll up, the toolbar, rubber-band scrolling, a finger scroll.

Visual difference:
- Only while a digit rolls (under 1 second, once a second). Table: what differs | how much | when.
