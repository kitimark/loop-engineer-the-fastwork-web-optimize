# PR-009: Platform section at rest: sweep and dash glint on the GPU (not pixel-identical: dash edge differs on iPhone WebKit)

## Problem

Not pixel-identical, first: on iPhone WebKit (Simulator) the grey dashes' bottom edge pixels differ by up to 17 of 255 the WHOLE TIME the glint is mounted, not only while it passes (first picture). The problem: at the bottom of the page (the #platform section) the page never rests. The colour sweep inside the four titles re-runs style every frame, and the glint on the dashed line repaints every frame. Pre-registered counts at rest (P-077), per 4 s sweep cycle: Chrome style 240 -> 8, paints about 481 -> 33; Simulator style about 478 -> 8, layouts about 237 -> 8, paints about 952 -> 4.

## Idea

Both effects move as GPU transforms of the same gradient: the sweep as a band behind a text-shaped mask, the glint as a gradient strip clipped to the dash's exact shape. Same timing, same 1 s start delay, same stop when scrolled away, reduced motion unchanged.

## Looks the same?

Same colours, same speed, same shape and timing; the differences are sub-pixel edge and phase shades (numbers below), measured on frozen frames at the same moment.

## Risk

Pixel rule exception needed (look-alike). The dash-edge shade on WebKit is permanent while the glint is mounted. Before landing, the lead runs one short phone no-worse check after your choice.

## Options

### Option both: Sweep + glint on the GPU

Both changes (G1 + G3). The platform tail stops causing redraws at rest.

Risk: Pixel-rule exception (look-alike): the WebKit dash-edge shade stays while the glint is mounted. Lands only after the lead's short phone no-worse check.

Visual difference:
- iPhone WebKit: the grey dashes' bottom edge row is up to 17/255 different the whole time the glint is mounted (the dash gets its own GPU layer)
- Glint edges while it passes: up to 64/255 in Chrome, 33/255 in WebKit, top and bottom edge pixels only; the inside is the same
- Colour sweep inside the titles: shifted by under a third of a device pixel; up to 9/255 on phones, 23/255 on a 1440 px desktop, 10/255 in WebKit
- Reduced motion: identical

### Option sweep-only: Sweep on the GPU, glint as today

Only G3. The dashed line and its glint stay exactly as today (no dash-edge difference anywhere).

Risk: Pixel-rule exception for the sweep only (sub-pixel phase shades). About half the saving: the glint keeps repainting every frame. Phone no-worse check before landing.

Visual difference:
- Colour sweep inside the titles: up to 9/255 on phones, 23/255 on a 1440 px desktop, 10/255 in WebKit
- Dash and glint: identical (unchanged code)
